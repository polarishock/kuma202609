# App Icons
Place your app icons in this directory. To ensure the browser can read them correctly, please use the following filenames:

### Required Filenames:
- **`favicon-32x32.png`**: Standard icon for browser tabs (32x32 pixels).
- **`favicon-16x16.png`**: Smaller icon for browser tabs (16x16 pixels).
- **`apple-touch-icon.png`**: Icon for iPhone/iPad home screen (180x180 pixels).

### Recommended Formats:
- **PNG (Recommended)**: Best for icons because it supports transparency.
- **SVG**: Great for scalability and high-resolution displays.
- **ICO**: Traditional format for `favicon.ico`.
- **JPG**: Not recommended for icons as it lacks transparency.
